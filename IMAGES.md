## Image tone guidance

Supported living imagery should feel distinct from domiciliary care or care home photography:

- **The resident is the subject.** Support workers are supporting characters.
- **Their home, not a facility.** Real homes look lived-in: décor, plants, personal items, everyday mess.
- **Capable and active.** Show people doing things, going places, making choices — not passively receiving care.
- **Diverse.** Reflect London's diversity in ethnicity, age, disability visibility and cultural background.
- **Natural light and real settings.** Avoid studio shots, matching uniforms in clinical environments, or anything that looks like a stock-photo care scene.

## Generating images with the script

Run `scripts/generate-images.js` to generate images via Stability AI:

```bash
STABILITY_API_KEY=sk-your-key-here npm run images:generate
```

The script generates all entries in its `IMAGES` array and overwrites existing files. To generate only specific images (e.g. 10–23), edit the array to comment out the ones you want to skip.

See `scripts/generate-images.js` for the full prompt list. Add new entries there and in this file together when adding new images.

## Adding a new image

1. Drop the file into `public/images/` as `N.jpg` (next number after 23)
2. Add an entry to this file under the relevant section
3. Add the prompt to `scripts/generate-images.js` if you want it script-generated
4. Reference it in JSX as `/images/N.jpg` or in a blog post seed as `imageUrl: "/images/N.jpg"`

### Recommended formats
- Photos: **JPG** at 80–85% quality — under 200 KB for thumbnails, under 400 KB for hero/wide images
- Logos / icons: **SVG** (scalable, no quality loss)
